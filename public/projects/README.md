# Project screenshots

Drop real screenshots of your websites here, named after the project's `slug`
in `lib/data.js`, for example:

- zenith-drive.jpg
- skyvora.jpg
- veloura-patisserie.jpg

Then add `image: '/projects/zenith-drive.jpg'` to that project in `lib/data.js`.
Recommended size: 1600 x 1000 px (16:10), JPG or WebP, under 300 KB.

A project with an `image` shows the screenshot instead of the live preview
(stacked cards) or the name card (scrolling showcase).
